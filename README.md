## What Is PlugOS?

**PlugOS** is a beginner Python terminal game and learning project.

The game itself is currently a small text-based trading prototype. The player earns money, buys and sells items, tracks reputation, advances through days, and works toward a cash goal.

But the real purpose of this repository is bigger than the game.

This project is an experiment to see how well **OpenAI's ChatGPT** can teach someone to code from the ground up by building a real project step by step.

Not just by dumping finished code.

Not by pretending everything is easy.

The goal is to use ChatGPT as a coding mentor: explaining concepts, reviewing mistakes, suggesting improvements, and helping turn a rough idea into a working project while the human actually learns what the code does.

---

## The Experiment

This repository is tracking two things at the same time:

1. **The game being built**
2. **The process of learning to code with ChatGPT as the teacher**

The point is to find out whether an AI assistant can be useful as more than an answer machine.

Can it explain ideas clearly?  
Can it spot messy beginner code?  
Can it help structure a project without taking over completely?  
Can it teach the reasoning behind the code instead of just writing it?

That is what PlugOS is testing.

## Current Stage

PlugOS is currently in the early prototype stage.

The current version includes:

- A working Python terminal loop
- A menu system
- Cash tracking
- Reputation tracking
- Day tracking
- Basic inventory tracking
- Buying and selling
- Random market prices
- A simple win condition

The project is intentionally simple right now. That is the point. The focus is on learning the foundations properly before adding bigger systems.

## Learning Goals

This project is being built around practical lessons, including:

- Python program flow
- Variables and state
- Functions
- User input
- Validation
- Game loops
- Dictionaries
- Reusable systems
- Data-driven design
- Saving and loading
- Project structure
- Git and GitHub workflow

Each feature should teach something useful. If a feature does not teach anything or improve the game, it can wait.

## Project Philosophy

The rules for this project are simple:

- Learn by building
- Understand before expanding
- Keep the code readable
- Refactor when the mess becomes real
- Commit progress regularly
- Let ChatGPT guide, but do not let it replace learning

The game may be rough. The early code may be ugly. That is normal.

The important thing is that each stage becomes clearer, stronger, and easier to build on.
